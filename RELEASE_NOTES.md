# Clipboard Vault 1.00 Beta

First public beta for Windows 11 x64.

## Install

1. Download and extract `ClipboardVault-1.00-Beta-Windows11-x64.zip`.
2. Run `INSTALL.cmd`.
3. Open Clipboard Vault from the Start menu.

Windows can show an Unknown publisher warning because this beta is unsigned.
Download it only from this repository and verify the published SHA-256 checksum.

## Included

- Quick Paste and Full Vault.
- Text, link, code, image and file history.
- Search, filters, pinned items, snippets and Stack Mode.
- Encrypted SQLite storage and authenticated encrypted images.
- Windows Hello or PIN lock.
- Authenticated backup and restore.
- Light, dark and system themes.
- Update rollback and user-data preservation.
